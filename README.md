Проект запускается так:
1) Устанавливаются зависимости (pip install -r requirements.txt)
2) Создаем БД (python3 manage.py migrate)
3) Запускаем сервер (python3 manage.py runserver)
4) Далее мы получаем сообщение об успешном запуске сервера: "Django version 4.2.27, using settings 'Hackathon_python.settings'
Starting development server at http://127.0.0.1:8000/"

Model: Book. Модель описывает структуру книги: название, автора, год, жанр, статус чтения и связь с пользователем через ForeignKey, обеспечивает валидацию данных через clean().

Controler: View. Обработка запросов через функцию request (получение данных из модели) и передача полученных данных в шаблон.

Template: HTML-файлы в папке /templates c использованием Bootstrap 5. Здесь соблюдается условие не содержть бизнес-логику.

Все задачи распределялись через issues. Для удобства каждый участник создал свою ветку (users_s, books, Hackaton_python). По мере выполнения задач таски закрывались и после согласования финального вида проекта, был осуществлен pull request и сливание всего файла в main. Также мы сделали проект расширяемым: в дальнейшем к книге можно будет добавить обложку и другие фичи.
